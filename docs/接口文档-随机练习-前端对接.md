# 学生随机练习 · 前端对接文档

> 适用版本：`main` @ 2026-11-16（随机组卷支持按题型/难度/题量筛选）
> 后端地址：`http://47.108.200.73`

---

## 1. 整体流程

```
① 学生点「随机组卷开始练习」
        ↓ 弹出选择框（题型 / 难度 / 题量）
② POST /api/exam/practice/random/     → 返回 sheet_id + 题目列表
        ↓ 学生逐题作答
③ PUT  /api/exam/answer-sheets/{sheet_id}/answers/    → 自动/手动保存进度
        ↓ 点「提交」
④ POST /api/exam/answer-sheets/{sheet_id}/submit/     → 客观题自动判分
        ↓
⑤ GET  /api/exam/practice/{sheet_id}/sheets/          → 查看答案解析与得分
```

列表页用 `GET /api/exam/practice/sheets/` 拉练习记录。

---

## 2. 通用约定

### 2.1 请求头

```
Authorization: Bearer <access_token>
Content-Type: application/json
```

登录接口：`POST /api/auth/login/`，body `{"username": "...", "password": "..."}`，返回 `data.access` / `data.refresh`。

### 2.2 统一响应信封

**成功**

```json
{ "code": 0, "message": "ok", "data": { ... } }
```

**失败**

```json
{ "code": 400, "message": "题库中没有符合条件（学科/题型/难度/年级）的试题，无法组卷", "data": null }
```

| code | 含义 |
| --- | --- |
| 0 | 成功 |
| 400 | 参数错误 / 业务校验不通过 |
| 401 | 未登录或 token 过期 |
| 403 | 无权限（如非学生角色） |
| 404 | 资源不存在 |
| 409 | 状态冲突（如已提交后再次修改） |
| 500 | 服务器内部错误 |

> 失败时直接展示 `message` 字段即可，文案已做中文处理。

## 3. 接口一：随机组卷并创建练习答卷

```
POST /api/exam/practice/random/
权限：学生
```

### 3.1 请求参数

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `subject` | string | **是** | 学科：`music`（音乐）/ `art`（美术） |
| `question_count` | int | 否 | 总题数。不传则按默认配置抽 |
| `qtypes` | array\<string\> | 否 | 题型过滤，如 `["single", "judge"]`；也兼容 `"single,judge"` 字符串 |
| `difficulties` | array\<string\> | 否 | 难度过滤，如 `["easy", "medium"]`；也兼容逗号分隔字符串 |
| `chapter_id` | int | 否 | 限定章节 |
| `grade` | string | 否 | 适用年级。**不传**则自动取学生所在班级的年级；传 `""` 或 `"all"` 表示不限年级 |

#### 题型枚举 `qtypes`

| 值 | 含义 | 是否需要学生输入文本 |
| --- | --- | --- |
| `single` | 单选题 | 否（选项选择） |
| `multiple` | 多选题 | 否（多选） |
| `judge` | 判断题 | 否 |
| `fill` | 填空题 | 是 |
| `short` | 简答题 | 是（主观题，不自动判分） |
| `listening` | 听力题 | 视资源而定 |
| `sight` | 视唱/识谱题 | 是（主观题） |

#### 难度枚举 `difficulties`

| 值 | 含义 |
| --- | --- |
| `easy` | 简单 |
| `medium` | 中等 |
| `hard` | 困难 |

### 3.2 请求示例

**场景 A：不带筛选（兼容旧行为）**

```json
{ "subject": "music" }
```

**场景 B：10 道单选题**

```json
{ "subject": "music", "question_count": 10, "qtypes": ["single"] }
```

**场景 C：简单 + 中等难度，共 5 道，不限年级**

```json
{
  "subject": "art",
  "question_count": 5,
  "difficulties": ["easy", "medium"],
  "grade": "all"
}
```

**场景 D：只要判断题和填空题**

```json
{ "subject": "art", "qtypes": "judge,fill" }
```

```json
  "message": "组卷成功",

      "subject": "music",

      "question_count": 5

    "questions": [
      {
        "id": 101,

        "qtype_display": "单选题",

        "grade": "三年级",
        "stem": "以下哪个是高音谱号？",
        "options": [
          { "key": "A", "text": "𝄞" },
          { "key": "B", "text": "𝄢" }
        ],
        "score": "2.00",
        "resources": [
          { "id": 3, "rtype": "audio", "url": "http://47.108.200.73/media/question/2026/11/a.mp3" }

      "grade": "三年级"
    }

```

### 3.4 字段说明

| 字段 | 说明 |
| --- | --- |
| `sheet.id` | **答卷 id**，后续保存/提交/查看详情都用它 |
| `paper.question_count` | 实际抽到的题目数 |
| `questions[]` | 题目列表，按 `sort` 排序；**未提交前不含 `answer` / `analysis`** |
| `questions[].options` | 仅客观题有值，格式 `[{key, text}]` |
| `questions[].resources` | 音频/图片/视频；`rtype` = `audio` / `image` / `video` |
| `meta.requested_count` | 前端请求的题数（未传为 0） |
| `meta.picked_count` | 实际抽到的题数 |
| `meta.available_count` | 符合条件的题库总量 |
| `meta.shortage` | 题数缺口 = `requested_count - picked_count`，**> 0 表示题库不足** |

### 3.5 抽题规则（前端了解即可）

- 只抽已审核（`approved`）的题；
- 传 `question_count` → 在过滤后的题库中随机抽 N 道，**不足则有多少给多少**；
- 只传 `qtypes` 没传 `question_count` → 随机抽 10 道；
- 什么都不传 → `单选5 + 多选2 + 判断3 + 填空2`，题型不足自动降级。

### 3.6 错误示例

```json
{ "code": 400, "message": "subject 仅支持 music / art", "data": null }
{ "code": 400, "message": "不支持的题型：abc", "data": null }
{ "code": 400, "message": "不支持的难度：veryhard", "data": null }
{ "code": 400, "message": "question_count 必须是整数", "data": null }
{ "code": 400, "message": "题库中没有符合条件（学科/题型/难度/年级）的试题，无法组卷", "data": null }
```

## 4. 接口二：保存答题进度

```
PUT /api/exam/answer-sheets/{sheet_id}/answers/
权限：学生（本人答卷）
```

### 请求体

```json
{
  "answers": [
    { "question_id": 101, "answer": "A" },
    { "question_id": 102, "answer": "ACD" },
    { "question_id": 103, "answer": "正确" },
    { "question_id": 104, "answer": "440" }
  ]
}
```

| 字段 | 说明 |
| --- | --- |
| `question_id` | 必须是本卷题目 |
| `answer` | 单选题传选项 key（`"A"`）；多选题传拼接串（`"ACD"`）；判断题传 `"正确"` / `"错误"`；填空题/简答题传文本 |

### 响应

```json
{
  "code": 0,
  "message": "保存成功",
  "data": { "sheet_id": 88, "saved": 4, "is_submitted": false }
}
```

> 幂等：同一题重复保存会覆盖。已提交的答卷再保存会返回 `409`。

## 5. 接口三：提交答卷

```
POST /api/exam/answer-sheets/{sheet_id}/submit/
权限：学生（本人答卷）
```

无请求体。提交后客观题自动判分。

### 响应

```json
{
  "code": 0,
  "message": "提交成功",
  "data": {
    "id": 88,
    "paper_id": 61,
    "publish_id": null,
    "started_at": "2026-11-16T10:30:00+08:00",
    "submitted_at": "2026-11-16T10:45:12+08:00",
    "is_submitted": true,
    "total_score": "7.00",
    "paper_total_score": "9.00",
    "correct_count": 3,
    "wrong_count": 1,
    "subjective_pending": 1,
    "pass": true
  }
}
```

| 字段 | 说明 |
| --- | --- |
| `total_score` | 本次得分 |
| `correct_count` / `wrong_count` | 客观题对/错数量 |
| `subjective_pending` | 待人工/AI 评分的主观题数量 |
| `pass` | 是否达到 60% 及格线 |

## 6. 接口四：练习详情（含答案解析）

```
GET /api/exam/practice/{sheet_id}/sheets/
权限：学生（本人）
```

**未提交**：只返回题目，不含答案。
**已提交**：额外返回 `answer`、`analysis`、`my_answer`、`my_score`、`is_correct`，以及 `stats` 统计。

```
GET /api/exam/practice/sheets/?page=1&page_size=20
权限：学生
```

### 响应

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "list": [
      {
        "sheet_id": 88,
        "paper_id": 61,
        "title": "音乐练习卷 · 1116103000",
        "subject": "music",
        "subject_display": "音乐",
        "ptype": "practice",
        "ptype_display": "练习",
        "total_score": "9.00",
        "question_count": 5,
        "my_score": "7.00",
        "is_submitted": true,
        "started_at": "2026-11-16T10:30:00+08:00",
        "submitted_at": "2026-11-16T10:45:12+08:00"
      }
    ],
```

## 8. 前端交互建议

### 8.1 组卷前的选择弹窗

点「随机组卷开始练习」后，建议弹出表单：

| 控件 | 对应参数 | 建议默认值 |
| --- | --- | --- |
| 题型（多选 chips） | `qtypes` | 不选 = 全部题型 |
| 难度（多选 chips） | `difficulties` | 不选 = 全部难度 |
| 题量（数字输入/步进器） | `question_count` | 10，范围 1~50 |
| 年级（下拉，可选） | `grade` | 不选 = 跟随班级年级 |

### 8.2 题库不足的提示

拿到响应后判断 `meta.shortage`：

```js
if (res.data.meta.shortage > 0) {
  ElMessage.warning(
    `符合条件的题目只有 ${res.data.meta.available_count} 道，` +
    `本次已为你抽取 ${res.data.meta.picked_count} 道`
  )
}
```

### 8.3 空题库处理

`code === 400` 且 message 含「题库中没有符合条件」时，提示学生放宽筛选条件（减少题型/难度限制，或选择「不限年级」）。

### 8.4 题目去重说明

随机组卷每次会重新抽题，但**题库总量小于单次题量时，前后两次必然出现重复题目**——这不是 bug。若希望练习不重复，需要题库端把题量补充到单次抽取量的 2~3 倍以上。

### 8.5 渲染注意

- `options` 仅客观题存在，`judge` / `fill` / `short` 为空数组；
- `resources` 里的 `audio` 用 `<audio>` 渲染，`image` 用 `<img>`，`video` 用 `<video>`；
- 分数均以**字符串**返回（如 `"2.00"`），展示前按需 `Number()` 转换。
