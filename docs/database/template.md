# 数据库变更记录模板

> 每次数据库变更在本目录（`docs/database/`）以「表名.md」为文件名记录，例如 `exam_paper_publish.md`。

## 模板

- **表名**：<表名>
- **变更类型**：字段添加 / 字段修改 / 字段删除 / 表删除
- **SQL 语句**：
  ```sql
  <等价 DDL>
  ```
- **修改日期**：YYYY-MM-DD HH:mm:ss
- **修改人**：<git config user.name>

## 说明

- 变更类型只能从「字段添加 / 字段修改 / 字段删除 / 表删除」中选择。
- 同一次变更涉及多张表时，分别以各表名为文件名记录。
