## 一、通用约定

### 1.1 服务地址

| 环境 | Base URL |
| --- | --- |
| 本地 | `http://127.0.0.1:8000` |
| 测试服 | `http://47.108.200.73:81` |

### 1.2 认证

除登录接口外，全部需要 JWT：

```
Authorization: Bearer <access_token>
```

登录：`POST /api/auth/login/`，body `{"username": "...", "password": "..."}`，返回 `data.access`。

### 1.3 统一响应

```json
{ "code": 0, "message": "ok", "data": {} }
```

分页接口的 `data` 固定为：

```json
{ "list": [], "total": 0, "page": 1, "page_size": 20 }
```

分页参数：`page`（默认 1）、`page_size`（默认 20，最大 100）。

### 1.4 错误码

| code | HTTP | 含义 |
| --- | --- | --- |
| 0 | 200 / 201 | 成功 |
| 400 | 400 | 参数错误 |
| 401 | 401 | 未登录 / Token 失效 |
| 403 | 403 | 当前角色无权限 |
| 404 | 404 | 资源不存在或无权限访问（防越权统一返回 404） |
| 409 | 409 | 状态冲突 |
| 500 | 500 | 服务端异常 |

### 1.5 角色

`student` 学生、`teacher` 教师、`school` 学校管理员、`district` 区县管理员、`city` 市州管理员、`province` 省级管理员、`qb_admin` 题库管理员。

## 二、模块 1：学生练习测评（3 条）

权限：仅学生（`student`）。练习卷不产生证书。

### 2.1 随机组卷并创建练习答卷

`POST /api/exam/practice/random/`

**请求体**

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| subject | string | 是 | `music` / `art` |

```json
{ "subject": "music" }
```

**抽题规则**

1. 只抽该学科课程下 `status=approved` 的题；
2. 学生有已通过审核的班级且班级填了年级时，按该年级抽题，否则不限年级；
3. 默认 `single×5、multiple×2、judge×3、fill×2`，某题型不足时有多少抽多少；
4. 一题都抽不到返回 400。

**响应 201**

```json
{
  "code": 0,
  "message": "组卷成功",
  "data": {
    "sheet": {
      "id": 12, "paper_id": 30, "publish_id": null,
      "started_at": "2026-11-06T09:40:00+08:00", "submitted_at": null,
      "is_submitted": false, "total_score": "0.00"
    },
    "paper": {
      "id": 30, "title": "音乐练习卷 · 11060940", "subject": "music",
      "subject_display": "音乐", "ptype": "practice", "ptype_display": "练习",
      "duration": 0, "total_score": "9.00", "question_count": 5
    },
    "questions": [
      {
        "id": 5, "sort": 1, "qtype": "single", "qtype_display": "单选题",
        "difficulty": "easy", "grade": "三年级", "stem": "五线谱有几条线？",
        "options": [{"key": "A", "text": "三条"}, {"key": "B", "text": "四条"}], "score": "2.00",
        "resources": [{ "id": 1, "rtype": "audio", "url": "http://.../a.mp3" }]
      }
    ]
  }
}
```

**错误**

| 场景 | 返回 |
| --- | --- |
| subject 非 music/art | 400 `subject 仅支持 music / art` |
| 学科课程不存在 | 404 `未找到学科对应的课程：xxx` |
| 题库无可用题 | 400 `题库暂无该学科试题，无法组卷` |

答题过程复用已有接口：`PUT /api/exam/answer-sheets/{id}/answers/` 保存进度，`POST /api/exam/answer-sheets/{id}/submit/` 提交判分。

### 2.2 我的练习记录

`GET /api/exam/practice/sheets/`

仅返回 `publish` 为空的练习答卷，分页。

```json
{
  "list": [
    {
      "sheet_id": 3, "paper_id": 15, "title": "音乐练习卷 · 11060145",
      "subject": "music", "subject_display": "音乐",
      "ptype": "practice", "ptype_display": "练习",
      "total_score": "9.00", "question_count": 5,
      "my_score": "2.00", "is_submitted": true,
      "started_at": "2026-11-06T09:45:14+08:00",
      "submitted_at": "2026-11-06T09:45:25+08:00"
    }
  ],
  "total": 1, "page": 1, "page_size": 20
}
```

### 2.3 练习详情

`GET /api/exam/practice/{id}/sheets/`（`id` 为答卷 ID）

- 未提交：`questions` 不含答案与解析；
- 已提交：每题额外返回 `my_answer / my_score / is_correct`，并返回 `stats`。

```json
{
  "code": 0, "message": "ok",
  "data": {
    "sheet": { "id": 3, "paper_id": 15, "publish_id": null, "is_submitted": true, "total_score": "2.00" },
    "paper": { "id": 15, "title": "音乐练习卷 · 11060145", "question_count": 5, "total_score": "9.00" },
    "questions": [
      { "id": 5, "sort": 1, "stem": "五线谱有几条线？", "score": "2.00",
        "answer": "C", "analysis": "五线谱为五条线", "my_answer": "C", "my_score": "2.00", "is_correct": true }
    ],
    "stats": {
      "my_score": "2.00", "total_score": "9.00",
      "correct_rate": 0.2, "score_rate": 0.2222,
      "correct_count": 1, "wrong_count": 0, "subjective_count": 4
    }
  }
}
```

不存在或非本人：404 `练习答卷不存在`。

## 三、模块 2：趣味课堂（4 条）

| 操作 | 接口 | 权限 |
| --- | --- | --- |
| 列表 / 详情 | `GET /api/exam/fun-contents/`、`GET /api/exam/fun-contents/{id}/` | 学生、省级 |
| 新增 | `POST /api/exam/fun-contents/` | 仅省级 |
| 修改 / 删除 | `PUT/PATCH/DELETE /api/exam/fun-contents/{id}/` | 仅省级 |
| 发布 / 撤回 | `POST /api/exam/fun-contents/{id}/publish/`、`.../recall/` | 仅省级 |

**学生可见范围（越权保护）**：`status=published`，且 `school` 为空或等于本人学校，且 `target_class` 为空或属于本人已通过审核的班级。省级可见全部（含草稿）。

### 3.1 列表

`GET /api/exam/fun-contents/`

| 参数 | 说明 |
| --- | --- |
| subject | `art` / `music` / `general` |
| status | `draft` / `published`（学生对强制 published，传了也忽略） |
| category | 分类精确匹配 |
| keyword | 模糊匹配标题 / 摘要 |
| page / page_size | 分页 |

```json
{
  "list": [
    {
      "id": 1, "title": "音乐小知识", "subject": "music", "subject_display": "音乐",
      "category": "乐理", "summary": "摘要", "content": "正文", "fun_fact": "小知识",
      "emoji": "🎵", "color": "#6C8CFF", "read_minutes": 3,
      "status": "published", "status_display": "已发布",
      "creator": 7, "creator_name": "周厅长",
      "school": null, "school_name": "",
      "target_class": null, "target_class_name": "",
      "published_at": "2026-11-06T09:33:10+08:00",
      "created_at": "2026-11-06T09:33:09+08:00",
      "updated_at": "2026-11-06T09:33:09+08:00"
    }
  ],
  "total": 1, "page": 1, "page_size": 20
}
```

### 3.2 详情

`GET /api/exam/fun-contents/{id}/`，字段同上。学生访问草稿返回 404。

### 3.3 新增

`POST /api/exam/fun-contents/`（JSON）

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| title | string | 是 | ≤128 |
| subject | string | 否 | `art` / `music` / `general`，默认 `general` |
| category | string | 否 | ≤64 |
| summary | string | 否 | ≤255 |
| content | string | 否 | 正文 |
| fun_fact | string | 否 | 趣味小知识 |
| emoji / color | string | 否 | ≤16 |
| read_minutes | int | 否 | 默认 3 |
| status | string | 否 | `draft`（默认）/ `published` |
| target_class | int | 否 | 目标班级 ID（不传=不限班级） |

`creator`、`school`、`published_at` 为只读，由后端注入；省级发布不绑定学校，`school` 恒为 `null`。

响应 201：`data` 为单条对象（字段同上）。

### 3.4 修改

`PUT /api/exam/fun-contents/{id}/`（全量）或 `PATCH`（局部），字段同新增。

### 3.5 发布 / 撤回

`POST /api/exam/fun-contents/{id}/publish/`：`status` 置为 `published` 并写入 `published_at`。

`POST /api/exam/fun-contents/{id}/recall/`：`status` 置回 `draft`，`published_at` 清空，学生端立即不可见。

两者响应均为 200，`data` 为更新后的对象，`message` 分别为 `发布成功` / `已撤回`。

### 3.6 删除

`DELETE /api/exam/fun-contents/{id}/`：软删除，返回 `{"code":0,"message":"删除成功","data":null}`。

## 四、模块 3：学生上传证书（4 条）

| 操作 | 接口 | 权限 |
| --- | --- | --- |
| 我的列表 | `GET /api/exam/cert-uploads/` | 学生 |
| 上传 | `POST /api/exam/cert-uploads/` | 学生 |
| 删除 | `DELETE /api/exam/cert-uploads/{id}/` | 学生（仅本人） |
| 待审列表 | `GET /api/exam/cert-uploads/review/` | 教师 |
| 审核 | `POST /api/exam/cert-uploads/{id}/review/` | 教师 |

教师范围：本人任教科目的已通过班级 + 本人担任班主任的班级；非本人班级的记录统一 404。

### 4.1 我的列表

`GET /api/exam/cert-uploads/`（可选 `status=pending|approved|rejected`）

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "list": [
      {
        "id": 1, "title": "钢琴十级证书",
        "cert_type": "competition", "cert_type_display": "竞赛证书",
        "subject": "music", "subject_display": "音乐",
        "issuer": "中国音乐学院", "obtained_at": "2026-05-01",
        "image": "cert-uploads/2026/11/cert.png",
        "image_url": "http://127.0.0.1:8000/media/cert-uploads/2026/11/cert.png",
        "note": "备注", "status": "pending", "status_display": "待审核",
        "student": 3, "student_name": "王同学", "class_name": "一班",
        "reviewer": null, "review_comment": "", "reviewed_at": null,
        "created_at": "2026-11-06T09:33:10+08:00"
      }
    ],
    "total": 1
  }
}
```

> 该接口不分页，固定返回 `{list, total}`。

### 4.2 上传

`POST /api/exam/cert-uploads/`，`Content-Type: multipart/form-data`

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| image | file | 是 | 字段名必须为 `image`；仅 `image/jpeg`、`image/png`；≤5MB |
| title | string | 是 | 超长自动截断到 128 |
| cert_type | string | 否 | `exam` / `competition` / `graduation` / `other`，非法值归为 `other` |
| subject | string | 否 | `art` / `music` / `comprehensive` / `other`，非法值归为 `other` |
| issuer | string | 否 | ≤128 |
| obtained_at | string | 否 | `YYYY-MM-DD` |
| note | string | 否 | 备注 |

**响应 201**：`data` 为单条对象（字段同 4.1），`message` 为 `上传成功`，初始 `status=pending`。

**错误**

| 场景 | 返回 |
| --- | --- |
| 缺少 image | 400 `请上传证书图片（字段名 image）` |
| title 为空 | 400 `证书标题不能为空` |
| 超过 5MB | 400 `证书图片不能超过 5MB` |
| 非 jpeg/png | 400 `仅支持 JPG / PNG 格式的图片` |
| 日期格式错误 | 400 `获得日期格式应为 YYYY-MM-DD` |
| 教师 / 管理员调用 | 403 |

### 4.3 删除

`DELETE /api/exam/cert-uploads/{id}/`：软删除，仅本人可删，非本人返回 404。

### 4.4 教师待审列表

`GET /api/exam/cert-uploads/review/?status=pending`

仅返回本人所带班级学生的记录，不分页，结构同 4.1。`status` 不传则返回全部。

### 4.5 教师审核

`POST /api/exam/cert-uploads/{id}/review/`（JSON）

```json
{ "approved": true, "comment": "材料齐全" }
```

- `approved` 为 `true / 1 / "1" / "true" / "True"` 时通过，其余一律驳回；
- 审核人、审核时间、审核意见自动写入；
- 非本人班级记录返回 404 `资源不存在`；
- 学生、学校管理员调用返回 403。

**响应 200**：`data` 为更新后的记录，`message` 为 `审核通过` / `已驳回`。

## 五、模块 4：试题资源独立管理（2 条）

| 操作 | 接口 | 权限 |
| --- | --- | --- |
| 列表 / 详情 | `GET /api/questionbank/resources/`、`/{id}/` | 教师、题库管理员、省级 |
| 新增 / 修改 / 删除 | `POST`、`PUT/PATCH`、`DELETE` | 题库管理员、省级 |

### 5.1 列表

`GET /api/questionbank/resources/?question=1&rtype=audio&page=1&page_size=20`

| 参数 | 说明 |
| --- | --- |
| question | 按试题 ID 过滤 |
| rtype | `audio` / `image` / `video` |

```json
{
  "list": [
    {
      "id": 1,
      "created_at": "2026-10-23T13:45:30+08:00",
      "updated_at": "2026-10-23T13:45:30+08:00",
      "is_deleted": false,
      "deleted_at": null,
      "rtype": "audio",
      "file": "http://127.0.0.1:8000/media/question/2026/10/demo.mp3",
      "question": 1
    }
  ],
  "total": 2, "page": 1, "page_size": 20
}
```

### 5.2 新增

`POST /api/questionbank/resources/`（multipart）

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| question | int | 是 | 所属试题 ID（独立路由需显式传；嵌套路由 `questions/{id}/resources/` 由后端注入） |
| rtype | string | 是 | `audio` / `image` / `video` |
| file | file | 是 | 资源文件 |

响应 201，`data` 为单条资源对象。

### 5.3 修改 / 删除

- `PATCH /api/questionbank/resources/{id}/`：可改 `rtype`、`file`；
- `DELETE /api/questionbank/resources/{id}/`：软删除，返回 `{"code":0,"message":"删除成功","data":null}`。

```bash
BASE=http://127.0.0.1:8000
for p in \
  /api/exam/practice/random/ /api/exam/practice/sheets/ /api/exam/practice/1/sheets/ \
  /api/exam/fun-contents/ /api/exam/fun-contents/1/ /api/exam/fun-contents/1/publish/ /api/exam/fun-contents/1/recall/ \

  /api/questionbank/resources/ /api/questionbank/resources/1/ ; do
  printf "%-45s" "$p"
  curl -s -o /dev/null -w "%{http_code}\n" "$BASE$p"
done
```
