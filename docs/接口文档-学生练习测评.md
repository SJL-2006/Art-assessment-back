# 接口文档 · 学生练习测评（practice）

> 面向前端开发。覆盖学生自主练习模块的全部接口。
> 基地址：`http://<host>:8000`；鉴权：JWT，请求头 `Authorization: Bearer <access>`。
> 权限：以下接口均需 **student** 角色（`has_role(User.ROLE_STUDENT)`）。

---

## 1. 模块说明与完整流程

学生练习是「不发布、随时练」的场景，走以下流程：

```
① POST /api/exam/practice/random/        随机组卷 + 创建练习答卷（拿到 sheet_id + 题目）
② PUT  /api/exam/answer-sheets/{id}/answers/   保存答题进度（复用答卷接口）
③ POST /api/exam/answer-sheets/{id}/submit/    提交并自动判分（复用答卷接口）
④ GET  /api/exam/practice/{id}/sheets/   回看练习详情（答案/解析/正确率）
```

> ②③ 是 `answer-sheets` 模块的既有接口，对练习答卷（`publish=null`）同样适用，练习模块本身不重复提供。

- 练习卷 `ptype = "practice"`，与正式测评（`formal`）区分；练习卷不产生 `PaperPublish` 发布记录。
- 每题分值默认取题目本身分值（`Question.score`）；提交时客观题自动判分，主观题留空（练习默认只抽客观题，见 2.1 抽题规则）。

---

## 2. 接口列表

### 2.1 POST /api/exam/practice/random/ —— 随机组卷并创建练习答卷

**请求体**

```json
{ "subject": "music" }
```

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| subject | string | 是 | 学科，仅 `music`（音乐）/ `art`（美术） |

**抽题规则（后台固定，前端无需关心）**

- 只抽 `status=approved` 且属该学科课程的题；
- 若学生有已通过审核的班级且班级填了年级，则按该年级抽题；否则不限年级；
- 默认配置：`single×5、multiple×2、judge×3、fill×2`；某题型不足时**自动降级**（有多少抽多少）；
- 一题都抽不到 → 返回 400「题库暂无该学科试题，无法组卷」。

**响应（HTTP 201）**

```json
{
  "code": 0,
  "message": "组卷成功",
  "data": {
    "sheet": {
      "id": 88, "paper_id": 61, "publish_id": null,
      "started_at": "2026-11-05T12:30:00+08:00", "submitted_at": null,
      "is_submitted": false, "total_score": "0.00"
    },
    "paper": {
      "id": 61, "title": "美术练习卷 · 11051230",
      "subject": "art", "subject_display": "美术",
      "ptype": "practice", "ptype_display": "练习",
      "duration": 0, "total_score": "12.00", "question_count": 12
    },
    "questions": [
      {
        "id": 101, "sort": 1, "qtype": "single", "qtype_display": "单选题",
        "difficulty": "easy", "grade": "一年级", "stem": "以下哪个是蓝色？",
        "options": [{"key": "A", "text": "大海"}, {"key": "B", "text": "白云"}],
        "score": "1.00",
        "resources": [{"id": 3, "rtype": "image", "url": "http://<host>/media/question/2026/11/a.png"}]
      }
    ]
  }
}
```

**字段说明**

- `sheet`：练习答卷；`id` 即答卷 id，后续保存/提交/回看都用它。
- `paper`：练习卷信息；`question_count` 为抽到的题目总数。
- `questions`：题目列表，`sort` 为题号（从 1 开始），`options` 仅客观题有，`resources` 为音频/图片/视频资源。**未提交前不返回答案与解析**。

---

### 2.2 GET /api/exam/practice/sheets/ —— 我的练习记录

**查询参数**（沿用统一分页）

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| page | int | 页码，从 1 开始 |
| page_size | int | 每页条数，默认 20，最大 100 |

**响应**

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "list": [
      {
        "sheet_id": 88, "paper_id": 61,
        "title": "美术练习卷 · 11051230",
        "subject": "art", "subject_display": "美术",
        "ptype": "practice", "ptype_display": "练习",
        "total_score": "12.00", "question_count": 12,
        "my_score": "8.00", "is_submitted": true,
        "started_at": "2026-11-05T12:30:00+08:00",
        "submitted_at": "2026-11-05T12:35:00+08:00"
      }
    ],
    "total": 1,
    "page": 1,
    "page_size": 20
  }
}
```

**字段说明**

- `sheet_id`：答卷 id，用于跳转详情或继续作答。
- `my_score`：**仅已提交时有值**（字符串数字），未提交为 `null`。
- `total_score`：试卷满分；`question_count`：题目数。
- 列表仅返回「练习卷」（`publish` 为空）的答卷，正式测评答卷不在此接口出现。

---

### 2.3 GET /api/exam/practice/{id}/sheets/ —— 练习详情（回看）

**路径参数**：`id` = 答卷 id（即 `sheet_id`）。

**未提交时**：返回结构与 `random` 相同（`sheet` + `paper` + `questions`），题目**不含**答案/解析，**不含** `stats`。

**已提交时**：题目额外附带答案/解析与逐题作答结果，并多出 `stats`：

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "sheet": { "id": 88, "paper_id": 61, "publish_id": null, "is_submitted": true, "total_score": "8.00" },
    "paper": { "id": 61, "title": "美术练习卷 · 11051230", "subject": "art", "subject_display": "美术", "ptype": "practice", "ptype_display": "练习", "duration": 0, "total_score": "12.00", "question_count": 12 },
    "questions": [
      {
        "id": 101, "sort": 1, "qtype": "single", "qtype_display": "单选题",
        "difficulty": "easy", "grade": "一年级", "stem": "以下哪个是蓝色？",
        "options": [{"key": "A", "text": "大海"}], "score": "1.00", "resources": [],
        "answer": "A", "analysis": "蓝色对应大海",
        "my_answer": "A", "my_score": "1.00", "is_correct": true
      }
    ],
    "stats": {
      "my_score": "8.00", "total_score": "12.00",
      "correct_rate": 0.6667, "score_rate": 0.6667,
      "correct_count": 8, "wrong_count": 4, "subjective_count": 0
    }
  }
}
```

**字段说明**

- 逐题新增：`answer`（参考答案）、`analysis`（解析）、`my_answer`（我的作答）、`my_score`（该题得分）、`is_correct`（对/错；主观题为 `null`）。
- `stats`：
  - `correct_rate` = 正确题数 / 总题数；
  - `score_rate` = 得分 / 满分；
  - `subjective_count` = 未自动判分的主观题数（练习默认只抽客观题，通常为 0）。

---

## 3. 错误码（本模块）

| code | HTTP | message | 场景 |
| --- | --- | --- | --- |
| 400 | 400 | subject 仅支持 music / art | `subject` 缺失或非法 |
| 400 | 400 | 题库暂无该学科试题，无法组卷 | 该学科下无已通过试题 |
| 404 | 404 | 练习答卷不存在 | `id` 不存在 / 非本人 / 非练习卷 |
| 401 | 401 | 未登录 | 无 token |
| 403 | 403 | 没有操作权限 | 非 student 角色 |

---

## 4. 复用接口（保存进度 / 提交判分）

练习答卷与正式答卷共用 `answer-sheets` 模块：

### 4.1 PUT /api/exam/answer-sheets/{id}/answers/ —— 保存答题进度

```json
{ "answers": [ { "question_id": 101, "answer": "A" }, { "question_id": 102, "answer": "B,C" } ] }
```

响应：`{ "code": 0, "message": "保存成功", "data": { "sheet_id": 88, "saved": 2, "is_submitted": false } }`

### 4.2 POST /api/exam/answer-sheets/{id}/submit/ —— 提交并自动判分

无请求体。响应 `data` 含 `correct_count / wrong_count / subjective_pending / pass` 等。
