## 二、需新增的 4 组接口（13 条路由）

### 模块 1：学生练习测评 `/api/exam/practice/`（3 条）

路由注册：`router.register("practice", practice_views.PracticeViewSet, basename="practice")`

| 方法 | 路由 | 功能 | 权限 |
|------|------|------|------|
| POST | `/practice/random/` | 按学科随机组卷并创建练习答卷，返回 201 | 学生 |
| GET | `/practice/sheets/` | 我的练习记录（`publish` 为空的答卷） | 学生 |
| GET | `/practice/{id}/sheets/` | 练习详情，已提交才返回答案/解析+正确率 | 学生本人 |

- 请求体 `random`：`{"subject": "music"}`，仅接受 `music / art`。
- **抽题规则**：只抽 `status=approved` 且属该学科课程的题；有已通过审核班级且班级填了年级则按该年级抽，否则不限年级；默认 `single×5、multiple×2、judge×3、fill×2`，某题型不足自动降级；一题都抽不到返回 400 `题库暂无该学科试题，无法组卷`。
- 详情路由是 `practice/{id}/sheets/`（`detail=True`、`url_path="sheets"`），**不是** `practice/sheets/{id}/`。
- 依赖 `services.py` 已有 3 个 payload helper。

### 模块 2：趣味课堂 `/api/exam/fun-contents/`（4 条）

路由注册：`router.register("fun-contents", views.FunContentViewSet, basename="fun_content")`

| 方法 | 路由 | 权限 |
|------|------|------|
| GET | `/fun-contents/`、`/{id}/` | 学生、省级 |
| POST | `/fun-contents/` | 仅省级 |
| PUT/PATCH/DELETE | `/{id}/` | 仅省级 |
| POST | `/{id}/publish/`、`/{id}/recall/` | 仅省级 |

- **模型 `FunContent`**（表 `exam_fun_content`，迁移 `0008`）字段：`title / subject(art|music|general) / category / summary / content / fun_fact / emoji / color / read_minutes / status(draft|published) / creator / school / target_class / published_at`。
- **学生可见范围（越权保护）**：仅 `status=published`；`school` 为空或等于本人学校；`target_class` 为空或属于本人已通过审核的班级。省级可见并管理全部。
- 查询参数：`subject / status / category / keyword`（匹配 title/summary）、分页 `page/page_size`。
- `creator / school` 只读，后端注入（省级发布不绑定学校/班级）。

### 模块 3：学生上传证书 `/api/exam/cert-uploads/`（4 条）

路由注册：`router.register("cert-uploads", student_views.UploadedCertificateViewSet, basename="cert_upload")`

| 方法 | 路由 | 权限 | 说明 |
|------|------|------|------|
| GET | `/cert-uploads/` | 学生 | 仅本人数据，返回 `{list,total}` |
| POST | `/cert-uploads/` | 学生 | multipart 上传 |
| DELETE | `/cert-uploads/{id}/` | 学生 | 软删，仅本人 |
| GET | `/cert-uploads/review/?status=pending` | 教师 | 仅本人所带班级学生 |
| POST | `/cert-uploads/{id}/review/` | 教师 | 非本班记录返回 404（防越权） |

- **模型 `UploadedCertificate`**（表 `exam_uploaded_certificate`，迁移 `0007`）字段：`title / cert_type(exam|competition|graduation|other) / subject(art|music|comprehensive|other) / issuer / obtained_at / image / note / status(pending|approved|rejected) / reviewer / review_comment / reviewed_at`。
- **上传校验**：`image` 必填且字段名必须为 `image`；仅 `image/jpeg`、`image/png`；≤5 MB；`title` 必填、超长截断到 128；`obtained_at` 可选 `YYYY-MM-DD`；`cert_type/subject` 非法值由 choices 兜底为 `other`。
- 审核请求体：`{"approved": true, "comment": "..."}`（`approved` 非 `true/1/"1"/"true"/"True"` 即驳回）。

### 模块 4：试题资源独立管理 `/api/questionbank/resources/`（2 条）

路由注册：`router.register("resources", views.QuestionResourceViewSet, basename="resource")`

| 方法 | 权限 |
|------|------|
| GET（列表/详情） | 教师、题库管理员、省级 |
| POST/PATCH/DELETE | 题库管理员、省级 |

- 模型 `QuestionResource` **已存在**（表 `qb_question_resource`），**无需新增迁移**，只需补 ViewSet + Serializer + 路由。
- 查询参数：`question`（按试题 id）、`rtype`（`audio|image|video`）、分页。响应字段：`id / question / rtype / file`。

## 五、线上配置 / 安全修正（与补丁一并处理）

1. **`DEBUG=True` 泄漏**：404 会暴露全部路由与环境变量键名 → 切 `config.settings.prod`（`DJANGO_SETTINGS_MODULE`）。
2. **`CORS_ALLOW_ALL_ORIGINS=True`** → 收敛为前端域名白名单。
3. **`/media` 未映射** → Nginx 加 `location /media/ { alias <MEDIA_ROOT>/; }`，否则证书图片/试题音频 404。
4. **确认用 MySQL**（`prod.py` 已默认 MySQL），避免 SQLite 并发锁。
5. **清理历史 mock 路由**（若服务器存在）。
6. Nginx 反向代理时 prod settings 增加 `SECURE_PROXY_SSL_HEADER = ("HTTP_X_FORWARDED_PROTO", "https")`。

## 六、部署步骤

```bash
# 0. 备份
mysqldump -u<user> -p<pwd> <db> > backup_$(date +%F_%H%M).sql
tar -czf code_backup_$(date +%F_%H%M).tar.gz apps/exam apps/questionbank

# 1. 上传/合并补丁（覆盖 apps/exam、apps/questionbank）
# 2. 依赖（requirements 无新增可跳过）
pip install -r requirements.txt
# 3. 校验迁移（应无漏生成）
python manage.py makemigrations --check --dry-run
# 4. 执行迁移
python manage.py migrate --settings=config.settings.prod
# 5. 静态资源
python manage.py collectstatic --settings=config.settings.prod --noinput
# 6. 重启后端（按实际方式）
supervisorctl restart art-backend
# 或
pkill -f gunicorn && gunicorn config.wsgi:application --env DJANGO_SETTINGS_MODULE=config.settings.prod -b 127.0.0.1:8000 -w 3 -D
```

## 七、验证

未带 Token 时，路由存在应返回 **401/405**（而非 404），响应体为几十字节 JSON：

```bash
BASE=http://47.108.200.73:81
for p in \
  /api/exam/practice/random/ /api/exam/practice/sheets/ /api/exam/practice/1/sheets/ \
  /api/exam/fun-contents/ /api/exam/fun-contents/1/ /api/exam/fun-contents/1/publish/ /api/exam/fun-contents/1/recall/ \
  /api/exam/cert-uploads/ /api/exam/cert-uploads/1/ /api/exam/cert-uploads/review/ /api/exam/cert-uploads/1/review/ \
  /api/questionbank/resources/ /api/questionbank/resources/1/ ; do
  printf "%-45s" "$p"
  curl -s -o /dev/null -w "%{http_code}  %{size_download}B\n" "$BASE$p"
done
```

预期：13 行全为 401（只接受 POST 的 `random/publish/recall/review` 可为 405）。仍 404 且返回 KB 级 HTML 说明补丁未生效或未重启。
