# 接口文档 · 组卷暂存（draft）

> 面向前端开发。覆盖试卷「暂存题目与分值」接口。
> 基地址：`http://<host>:8000`；鉴权：JWT，请求头 `Authorization: Bearer <access>`。
> 权限：teacher / school / district / city / province（即试卷相关管理角色，不含 student / qb_admin）。

---

## 1. 接口概述

- 接口：`POST /api/exam/papers/{id}/draft/`
- 功能：按请求顺序**重建**该试卷的题目关联，并置为草稿；`total_score` 同步为本次关联分值之和。
- 兼容两种请求格式（见 2）；两者同时传入时**优先使用新版 `questions`**。

---

## 2. 请求体

### 2.1 新版格式（逐题分值，推荐）

```json
{
  "questions": [
    { "question_id": 101, "score": 5 },
    { "question_id": 205, "score": 1 }
  ]
}
```

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| questions | array | 是 | 题目数组，**数组顺序即题目顺序**，写入 `sort`（从 1 开始） |
| questions[].question_id | int | 是 | 有效题目 ID |
| questions[].score | number | 是 | 该题分值，**非负、允许 0**（与前端校验一致） |

### 2.2 旧版格式（兼容）

```json
{ "question_ids": [101, 205] }
```

- 保持旧行为：按数组顺序重建关联，每题分值沿用题目默认分值（`Question.score`）。
- 不得因新增 `questions` 格式破坏既有调用方。

---

## 3. 响应（HTTP 200）

```json
{
  "code": 0,
  "message": "暂存成功",
  "data": {
    "id": 9,
    "title": "期中美术测评",
    "ptype": "formal", "subject": "art", "level": "class",
    "grade": "", "duration": 40, "total_score": "6.00",
    "status": "draft", "creator": 3,
    "question_count": 2,
    "paper_questions": [
      {
        "id": 77, "sort": 1, "score": "5.00",
        "paper": 9,
        "question": {
          "id": 101, "qtype": "single", "qtype_display": "单选题",
          "difficulty": "easy", "grade": "一年级", "stem": "以下哪个是蓝色？",
          "options": [{"key": "A", "text": "大海"}], "answer": "A", "analysis": "蓝色对应大海"
        }
      },
      {
        "id": 78, "sort": 2, "score": "1.00",
        "paper": 9,
        "question": { "id": 205, "qtype": "judge", "qtype_display": "判断题", "stem": "……" }
      }
    ]
  }
}
```

**字段说明**

- `data` 为试卷完整对象；`paper_questions` 顺序即保存后的题目顺序，`score` 为保存的分值。
- `status` 保存后固定为 `draft`（草稿）。
- `total_score` = 本次所有题目分值之和。

---

## 4. 错误码

| code | HTTP | message | 场景 |
| --- | --- | --- | --- |
| 400 | 400 | 参数校验失败 | 缺少 `questions`/`question_ids`、数组为空、`score` 为负、缺 `question_id` 或缺 `score` 等（`data` 内为字段级错误） |
| 400 | 400 | 题目 ID 存在重复 | 请求中出现重复题目 |
| 400 | 400 | 部分试题不存在 | `question_id` 无对应题目 |
| 404 | 404 | 资源不存在 | `{id}` 对应试卷不存在或已软删除 |
| 403 | 403 | 没有操作权限 | 角色不在 teacher/school/district/city/province |

---

## 5. 校验失败示例

```json
{ "code": 400, "message": "参数校验失败", "data": { "questions": [ { "score": ["请确保该值大于或者等于 0。"] } ] } }
```

> 事务保证：任一步校验或写入失败即整体回滚，原试卷题目关联与状态**保持不变**，不会部分覆盖。
