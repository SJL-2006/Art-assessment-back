### 6.1 教师加入班级接口（科任教师申请）

**文件**：[apps/classroom/views.py](../apps/classroom/views.py)（ClassRoomViewSet 新增 action）

- **路径**：`POST /api/classroom/classes/{id}/join-teacher/`
- **对应 xlsx**：教师端「班级管理 → 加入班级」，与已有 #26 审核科任教师申请形成完整闭环
- **逻辑**：
  - 仅 `teacher` 角色可调用（学生/管理员 403）
  - 校验同校（klass.school_id == user.school_id）
  - 已存在 pending 记录 → 提示等待；approved → 提示已是科任教师；rejected → 重新提交
  - 新建 ClassTeacher(status=pending)，由班主任通过 #26 审核
- **运行时验证**：申请 201 / 重复申请 400 / 班主任审核通过 200 / 已是科任教师 400 / 学生调用 403 ✅

### 6.2 export_excel() 通用导出工具

**文件**：[apps/common/export.py](../apps/common/export.py)（新增）

- **用途**：A 文档「非接口硬活」明确要求；B/C 的所有「导出成绩/统计/证书」功能统一调用此工具
- **签名**：`export_excel(data, fields, filename="export.xlsx", sheet_name="Sheet1") -> HttpResponse`
  - `data`：支持 QuerySet / list[dict] / list[Model]
  - `fields`：`[(字段名, 表头), ...]`，字段支持模型属性或 dict key，自动处理 `get_xxx_display` 等 callable
- **实现**：openpyxl 生成 .xlsx → BytesIO → HttpResponse，Content-Disposition 用 RFC 5987 编码支持中文文件名
- **运行时验证**：QuerySet 导出 + list[dict] 导出 + openpyxl 回读校验表头/数据 ✅
