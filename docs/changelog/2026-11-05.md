## 记录二：组卷暂存接口兼容逐题分值（questions 格式）

- **需求**：前端 `paperDraft` 改发 `{questions: [{question_id, score}]}`，但后端 `POST /api/exam/papers/{id}/draft/`
  只接受 `question_ids`，导致报「question_ids: 该字段是必填项」；且逐题自定义分值无法保存。
  本次让接口同时接受新版 `questions` 与旧版 `question_ids`，两者同时传入优先 `questions`。
- **修改人**：userName（`git config user.name`）
- **修改日期**：2026-11-05
- **数据库变更**：无（仅接口请求体兼容与分值写入逻辑，未变更字段/表/索引/约束）。

无（仅替换请求体校验与分值赋值逻辑，未删除既有接口或模型）。

### 新增代码记录

1. `apps/exam/serializers.py`（修改）
   - 新增 `DraftQuestionSerializer`：`question_id`（`IntegerField(min_value=1)`）、
     `score`（`DecimalField(max_digits=5, decimal_places=2, min_value=0)`，允许 0）。
   - 修改 `DraftRequestSerializer`：新增可选字段 `questions`（`DraftQuestionSerializer(many=True)`），
     并将 `question_ids` 改为可选；`validate` 校验至少提供两者之一（空数组视为未提供）。

2. `apps/exam/views.py`（修改）
   - `draft` 动作改为按 `questions`（新版）优先、`question_ids`（旧版）兜底解析；
     新版按传入分值写 `PaperQuestion.score`，旧版沿用题目默认分值；
     重复题目 ID、无效题目 ID 仍返回 400；`total_score` 同步为本次关联分值之和；
     删除/重建/状态更新仍整体置于 `transaction.atomic()` 中。
