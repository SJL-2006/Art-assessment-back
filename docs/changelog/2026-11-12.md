# 代码修改记录 · 2026-11-12

## 记录一：登录接口 401 文案透传（密码错误 / 账号停用）

- **需求**：登录接口在「密码错误」「账号已停用」时前端统一显示「认证失败或凭证已过期」，用户误以为是 token/部署问题。根因：登录序列化器抛出的 DRF `AuthenticationFailed` 被全局异常处理器统一包装为固定文案，原始 message 被吞。
- **修改人**：userName（`git config user.name`）
- **修改日期**：2026-11-12
- **数据库变更**：无。

### 删除代码记录

无（仅将两处异常抛出类型由 `AuthenticationFailed` 改为业务异常 `ApiException`）。

### 新增代码记录

`apps/users/serializers.py`（修改）

- 新增 import：`from apps.common.exceptions import ApiException`、`from apps.common.response import ErrorCode`。
- `LoginSerializer.validate` 两处异常改为抛业务异常 `ApiException`，透传原始文案：
  - `raise drf_exc.AuthenticationFailed("用户名或密码错误")` → `raise ApiException("用户名或密码错误", code=ErrorCode.UNAUTHORIZED, status=401)`
  - `raise drf_exc.AuthenticationFailed("账号已停用")` → `raise ApiException("账号已停用", code=ErrorCode.UNAUTHORIZED, status=401)`

### 校验结果

- `python manage.py check`：✓ System check identified no issues (0 silenced)。
- 密码错误 → 401 `{"code":401,"message":"用户名或密码错误","data":null}`。
- 账号停用（临时置 is_active=False）→ 401 `{"code":401,"message":"账号已停用","data":null}`（测试后已恢复 is_active=True）。
- 正常登录 → 200 + access/refresh token。
- 伪造/过期 token 访问受保护接口 → 401 `{"code":401,"message":"认证失败或凭证已过期","data":null}`（全局行为不变）。
