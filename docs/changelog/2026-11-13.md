# 代码修改记录 · 2026-11-13

## 记录一：修复「试题管理·分类选音乐无题」bug

- **需求**：题库管理员端「试题管理」页，学科（分类）筛选选「音乐」后列表为空，但数据库中实际存在音乐题。
- **根因**：前端「学科/分类」筛选只在**当前分页（12 条）**内做客户端二次过滤，未传给后端；而试题默认按 `-id` 排序分页返回，音乐题分散在不同页，选中「音乐」时当前页常无（或极少）音乐题，表现为「根本没有题」。同时后端 `course` 筛选只接受单个课程 id，无法表达「音乐」这一跨多课程的学科（音乐拆分为 音乐鉴赏/高中音乐/小学音乐/初中音乐，`code` 均为 `music`）。
- **修改人**：userName（`git config user.name`）
- **修改日期**：2026-11-13
- **数据库变更**：无（未改动表结构，未新增/修改/删除字段、表、索引或约束）。

### 删除代码记录

`ART-front/frontend/src/views/questionbank/QuestionList.vue`（前端，独立仓库）

- `filteredList` 计算属性中删除「学科」的客户端二次过滤一行：
  `if (filterSubject.value && row.subject !== filterSubject.value) return false`（改为注释说明已走服务端过滤）。

### 新增代码记录

1. `apps/questionbank/views.py`（后端，修改）

   `QuestionViewSet.get_queryset` 新增 `subject` 筛选参数：
   - `subject=music` / `subject=音乐` → `filter(course__code="music")`；
   - `subject=art` / `subject=美术` → `filter(course__code="art")`。
   - 通过课程代码聚合「音乐」下所有课程，与既有 `course`（单个课程 id）筛选并存、互不影响。

2. `ART-front/frontend/src/views/questionbank/QuestionList.vue`（前端，修改）

   - `serverParams()` 新增：`if (filterSubject.value) p.subject = filterSubject.value === '美术' ? 'art' : 'music'`，将学科筛选下发给后端；
   - `filteredList` 移除学科客户端过滤（见上方删除记录），学科标签展示逻辑（`subjectOf`）保持不变。
