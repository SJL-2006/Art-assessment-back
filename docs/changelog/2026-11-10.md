2. `apps/questionbank/management/commands/generate_questions.py`（新建）
   - 新增 Django 管理命令 `generate_questions`，幂等批量生成题库。
   - 内置音乐（125 道）与美术（103 道）题目数据，按章节组织：
     - 音乐：乐理基础、乐器与乐队、音乐家与作品、民族音乐与民歌、音乐常识。
     - 美术：色彩基础、素描基础、构图与透视、中外美术史、美术门类、书法与民间美术。
   - 题型仅 `single`（单选）与 `judge`（判断），每题含题干、选项、答案、解析、难度、分值。
   - 写入时：适用年级按「一年级 ~ 六年级」循环分配，保证每个年级均有题可抽；
     状态统一置为 `approved`（已通过），使随机组卷/练习测评可直接抽到；
     以「学科 + 章节 + 题型 + 题干」为唯一键 `get_or_create`，重复运行不重复插入。
   - 辅助函数 `single()` / `judge()` 用于压缩选项与答案结构。
