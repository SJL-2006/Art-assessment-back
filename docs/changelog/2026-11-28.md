### 新增代码记录

1. `apps/org/management/commands/seed_sichuan_cities.py`（新增文件）：

   - 命令 `python manage.py seed_sichuan_cities`，参数 `--dry-run`（只统计不写库）、`--with-accounts`（为新增市州各创建 2 个市级管理员账号，默认不创建）。
   - 常量 `SICHUAN_CITIES`：21 个市州级行政区（18 地级市 + 3 自治州，code 采用国家标准区划代码），全部挂到「四川省」下（`level=city`、`parent=province`）；不含「天府新区/高新区」（它们已是成都市下的区县节点），不改成都市下现有 22 个区县。
   - `_ensure_province()`：`Region.update_or_create(code="510000")` 确保省级节点存在（`name=四川省 / level=province / parent=None / is_deleted=False`）。
   - 主流程：对每个市州 `Region.objects.update_or_create(code=code, defaults={name, level=city, parent=province, is_deleted=False, deleted_at=None})`，以 `code` 为唯一键幂等；已存在的成都市仅被更新为正确名称/层级/父级，不影响其下区县/学校/学生。
   - `--dry-run` 打印「新增 / 已存在 / 市州总数」及将新增的 code/name 清单，不写库。
   - `--with-accounts`：仅对**新增市州**（跳过成都市）各创建 `edu_{city.code}_01`、`edu_{city.code}_02` 两个 `role=city` 账号，`region=city`、`school=None`、密码统一 `123456`（`make_password` 哈希，与 `seed_chengdu_data` 一致）、`update_or_create(username=...)` 幂等；姓名复用 `seed_chengdu_data` 的 `_gen_adult_names`（内置成人姓名库，`random.Random(f"edu-{code}-city-admin")` 确定性生成，同一市州两账号不重名）；完整打印账号清单。
