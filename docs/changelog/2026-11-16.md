## 记录三：修复「题库管理员-试题审核·已通过角标显示 0」

- **需求**：服务器上「试题审核」页「已通过」列表有内容，但顶部标签按钮「已通过（N）」显示为 0。
- **根因**：
  1. 角标数字来自 `GET /api/questionbank/questions/stats/` 的 `approved` 字段；前端 `passedCount = stats.approved || 0`。
  2. `QuestionViewSet` 里同时存在**两个同名 `stats` action**（`url_path="stats"`）：一个返回 `{total, by_course}`（后合并进主分支的教师「试题库」版），一个返回 `{pending, approved, rejected, recent_reviews}`（审核页角标版）。Python 中后定义者覆盖前者，导致三处前端（试题库首页、教师试题库、试题审核角标）拿到的是**残缺字段**：审核页角标所需的 `approved` 要么缺失、要么整个接口在旧服务端上不存在，最终 `approved` 为 undefined → 0。
  3. 服务器后端运行的是旧代码（缺少 `approved` 字段或尚无该接口），故角标显示 0。
- **修改人**：userName（`git config user.name`）
- **修改日期**：2026-11-16 12:48:26
- **数据库变更**：无（纯代码调整，未改动表结构或数据）。

### 新增代码记录

`apps/questionbank/views.py`

- 将第二个 `stats` action 扩展为**字段合并版**，一次返回三处前端所需的全部字段：
  - `total`：未删除试题总数
  - `pending` / `approved` / `rejected`：按 `status` 统计的待审核/已通过/已驳回数量
  - `by_course`：各课程题量 `[{id, code, name, count}]`
  - `by_type`：题型分布 `{qtype: count}`
  - `recent_reviews`：最近 10 条审核记录（含 result/comment/question/reviewer/time）
