## 记录一：前端 dist 资源路径修复（相对路径打包）

- **需求**：用户反馈生成的 dist 打开后「不是前端页面」。排查确认：`vite.config.js` 未配置 `base`，Vite 默认按 `base: '/'` 打包，产物 `index.html` 与 CSS 里的资源引用为绝对路径 `/assets/...`。当直接双击 `index.html`（file:// 协议）或把 dist 部署到域名子目录时，这些绝对路径指向不到真实文件，导致 JS/CSS 全部加载失败、页面白屏，看起来像「不是前端页面」。

### 新增代码记录

1. `ART-front/frontend/vite.config.js`（修改）
   - `defineConfig` 中新增 `base: './'`：让打包产物 `index.html` 及 CSS 中的资源引用改为相对路径
     （`./assets/...`），从而在域名根目录、子目录、以及本地静态服务器下都能正确加载；
     项目路由为 hash 模式（`createWebHashHistory`），`base` 不影响路由跳转。

2. `ART-front/frontend/dist/`（重新构建）
   - 清理并重建产物：修复前 dist 因多次构建残留 4 份 index 入口及大量同名视图的重复 chunk；
     重建后为单一 index 入口（`index-C7U1Qk3p.js` / `index-VIa63eN0.css`）共 111 个资源文件。
   - 校验：`index.html` 引用 `src="./assets/index-C7U1Qk3p.js"`、
     `href="./assets/index-VIa63eN0.css"`；CSS 内图片引用为 `url(./student-bg-*.png)` 等相对路径，
     无 `/assets/...` 绝对路径残留。
