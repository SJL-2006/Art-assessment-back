## 记录七：修复「学生端音乐随机组卷练习」HTTP 400 报错

- **需求**：学生端「音乐随机组卷练习」接口 `POST /api/exam/practice/random/` 报 HTTP 400「题库中没有符合条件（学科/题型/难度/年级）的试题，无法组卷」，但教师端题库里音乐题数量充足。
- **根因**：`resolve_course(subject)` 用 `Course.objects.filter(code=subject).first()` 只取「code=music」的**第一条**课程。音乐学科拆成多条 code 均为 `music` 的课程（音乐鉴赏 / 初中音乐 / 高中音乐 / 小学音乐），`.first()` 抽到的那条课程题量为 0 或年级不匹配，导致按单课程过滤后无题；同时旧实现年级条件直接硬过滤，无逐级降级兜底。
- **修改人**：userName（`git config user.name`）
- **修改日期**：2026-11-19 09:10:05
- **数据库变更**：无（未改动表结构、字段、索引、约束；未新增/删除字段。仅回归验证时临时将美术已通过试题改为 pending 后立即恢复，未产生持久数据变更）。

### 删除代码记录

`apps/exam/practice_views.py`

1. 删除函数 `resolve_course(subject)`（原按 `Course.objects.filter(code=subject).first()` 取单条课程映射学科的旧实现）：

   ```python
   def resolve_course(subject):
       """把 Paper.subject（music/art）映射到 questionbank.Course。"""
       course = Course.objects.filter(code=subject).first()
       if course is None:
           name = SUBJECT_TO_COURSE_NAME.get(subject)
           course = Course.objects.filter(name=name).first() if name else None
       if course is None:
           raise ApiException(f"未找到学科对应的课程：{subject}", code=ErrorCode.NOT_FOUND, status=404)
       return course
   ```

2. 删除 `random()` 内「取单课程 → 按课程过滤」两行：

   ```

   ```

4. 删除旧报错文案（无自诊断信息）：

### 新增代码记录

`apps/exam/practice_views.py`

1. 新增 `_subject_questions(subject)`：**按课程代码（course.code）聚合**该学科全部题目，而非取单条课程；`code` 为空的历史课程退回按中文课程名匹配；两者都无课程时才抛 404：

   ```python
   def _subject_questions(subject):
       qs = Question.objects.filter(course__code=subject, is_deleted=False)
       name = SUBJECT_TO_COURSE_NAME.get(subject)
       if not qs.exists() and name:
           course_ids = list(Course.objects.filter(name=name, is_deleted=False).values_list("id", flat=True))
           if course_ids:
               qs = Question.objects.filter(course_id__in=course_ids, is_deleted=False)
       has_code_course = Course.objects.filter(code=subject, is_deleted=False).exists()
       has_name_course = bool(name) and Course.objects.filter(name=name, is_deleted=False).exists()
       if not has_code_course and not has_name_course:
           raise ApiException(f"未找到学科对应的课程：{subject}", code=ErrorCode.NOT_FOUND, status=404)
       return qs
   ```

2. `random()` 内基础候选集改为按代码聚合：

   ```python
   base_qs = _subject_questions(subject).filter(status=Question.STATUS_APPROVED)
   ```

3. 新增**年级逐级降级**逻辑：班级年级精确过滤无题时，放弃年级条件以保底组卷，并用 `grade_relaxed` 标记：

   ```python
   grade_relaxed = False
   final_qs = base_qs
   if grade:
       grade_qs = base_qs.filter(grade=grade)
       if grade_qs.count() == 0:
           final_qs = base_qs
           grade_relaxed = True
       else:
           final_qs = grade_qs
   ```

4. 新增**自诊断报错文案**：空题库时返回学科/题型/难度/年级与「该学科已通过试题共 N 道」：

   ```python
   qtype_label = "、".join(dict(Question.TYPE_CHOICES).get(q, q) for q in qtypes) or "全部"
   difficulty_label = "、".join(dict(Question.DIFFICULTY_CHOICES).get(d, d) for d in difficulties) or "全部"
   approved_total = _subject_questions(subject).filter(status=Question.STATUS_APPROVED).count()
   raise ApiException(
       f"题库中没有符合条件的试题（学科：{dict(Paper.SUBJECT_CHOICES)[subject]}；"
       f"题型：{qtype_label}；难度：{difficulty_label}；年级：{grade or '不限'}）；"
       f"该学科已通过试题共 {approved_total} 道",
       code=ErrorCode.INVALID_PARAM, status=400,
   )
   ```

5. 抽题（含 `question_count` / `qtypes` / 默认题型配置三分支）统一改用 `final_qs` 抽样。

6. `meta` 新增 `grade_relaxed` 字段（标记是否发生年级降级）：

   ```python
   "grade_relaxed": grade_relaxed,
   ```
