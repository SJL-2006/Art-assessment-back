## 记录六：修复「试卷详情接口不返回题目」bug

- **需求**：组卷管理页试卷预览弹窗显示「展示 0 题，共 30 题」——`GET /api/exam/papers/{id}/` 详情返回的 `PaperSerializer` 不含嵌套 `paper_questions`，导致前端拿不到题目。根因：`PaperViewSet` 固定用 `serializer_class = PaperSerializer`，未按 action 切换序列化器。
- **修改人**：userName（`git config user.name`）
- **修改日期**：2026-11-11
- **数据库变更**：无。

### 删除代码记录

无。

### 新增代码记录

`apps/exam/views.py`（修改）

- `PaperViewSet` 新增 `get_serializer_class` 方法：`action == "retrieve"` 时返回 `PaperDetailSerializer`（含嵌套 `paper_questions` + `question_count`），其余动作（含 `list`）仍返回 `PaperSerializer`，保持列表轻量、不嵌套序列化全部题目。

### 校验结果

- `python manage.py check`：✓ System check identified no issues (0 silenced)。
- 登录 `teacher`/`123456` 获取 token：✓ 200。
- `GET /api/exam/papers/`：✓ 列表项不含 `paper_questions`，仅含 `question_count` 等轻量字段。
- `GET /api/exam/papers/{id}/`：✓ 详情含 `paper_questions`，长度与 `question_count` 一致；题量最大试卷（id=33，30 题）返回 `paper_questions` 长度 30，每项含 `question` 完整内容（stem/qtype/score）。
