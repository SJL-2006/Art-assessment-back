## 一、删除代码记录

1. `config/settings/dev.py`：删除「dev 模式数据库写死为 SQLite」的固定 `DATABASES` 配置，
   改为按环境变量 `DB_ENGINE` 在 SQLite / MySQL 之间切换。

---

## 二、新增代码记录

1. `requirements.txt`（修改）
   - 新增 `pymysql==1.1.*`：纯 Python 的 MySQL 驱动，Windows 下免编译，通过
     `install_as_MySQLdb()` 兼容 Django 的 MySQL 后端。

2. `config/__init__.py`（新增）
   - 新增 `pymysql.install_as_MySQLdb()`（包导入即生效），并兼容未安装驱动时静默跳过。

3. `config/settings/dev.py`（修改）
   - 新增 `DB_ENGINE` 环境变量开关：`mysql` 时使用 MySQL（`DB_NAME/DB_USER/DB_PASSWORD/DB_HOST/DB_PORT`，
     字符集 `utf8mb4`）；否则默认 SQLite（保持原行为，不影响既有本地开发）。

4. `.env.example`（修改）
   - 更新注释与示例：增加 `DB_ENGINE=mysql`，MySQL 五项（NAME/USER/PASSWORD/HOST/PORT）改为共享库示例占位。

5. `.env`（修改）
   - 更新注释说明：`DB_ENGINE=sqlite`（默认，保持本地 SQLite），并给出 MySQL 五项注释占位，
     待拿到云数据库地址后取消注释填写。

---

## 三、校验结果

- 默认行为不变：未设置 `DB_ENGINE=mysql` 时，`manage.py`（默认 `config.settings.dev`）仍走 SQLite，
  既有本地开发不受影响。
- 切换路径：`.env` 中 `DB_ENGINE=mysql` + 填齐五项 → `pip install -r requirements.txt` →
  目标库执行建库 SQL → `python manage.py migrate` → `python manage.py seed_demo`。
