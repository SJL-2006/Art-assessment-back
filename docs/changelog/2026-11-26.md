### 一、去除注册、账号统一下发（安全）

#### 删除代码记录

1. `apps/users/views.py`：删除 `RegisterView`（`AllowAny` + `CreateAPIView`）与 `SchoolCodeCheckView` 两个视图；删除 `RegisterSerializer`、`generics`、`AuthenticationFailed` 等不再使用的导入。

2. `apps/users/urls.py`：删除 `register/`、`school-check/` 两条路由，仅保留 `me/`、`me/avatar/`、`change-password/`。

3. `apps/users/serializers.py`：删除 `RegisterSerializer`。

#### 新增代码记录

1. `apps/users/views.py`：`LoginSerializer.validate` 兼容三种登录标识——用户名 / 学号(student_no) / 职工编号(staff_no)，命中后统一归一为 `username` 交给 simplejwt 完成密码校验：

   ```python
   def validate(self, attrs):
       username = (attrs.get(self.username_field) or "").strip()
       if username:
           user = (
               User.objects.filter(username=username, is_active=True).first()
               or User.objects.filter(student_no=username, is_active=True).first()
               or User.objects.filter(staff_no=username, is_active=True).first()
           )
           if user:
               attrs[self.username_field] = user.username
       return super().validate(attrs)
   ```

2. `apps/users/serializers.py`：新增 `ROLE_RANK`（角色层级）与 `validate_role_creation(caller, target_role)` 防越权建号——普通角色只能创建严格低于自己层级的账号，题库管理员(`qb_admin`)禁止经账号管理接口创建；`AccountManageSerializer.validate_role` 调用该校验。

3. `apps/users/views_accounts.py`：`batch_create`、`batch_import` 在生成账号前调用 `validate_role_creation(request.user, role)`，封堵「批量创建任意角色」的提权路径。

4. `apps/users/serializers.py`：`UserSerializer.Meta.read_only_fields` 增加 `school` / `region` / `student_no` / `staff_no`，身份字段个人不可自助修改，防止学生改写学籍号 / 教师改写职工编号 / 换学校。

### 二、多级数据隔离修复（安全）

#### 删除代码记录

1. `apps/common/scopes.py`：市州 / 区县两个分支原用两次 `.filter()` **AND** 叠加 `region` 与 `school` 条件，导致「region 级账号（school 为空）」被错误隐藏；改为 `Q(...) | Q(...)` **OR** 合并。

2. `apps/exam/search_views.py`：删除误用——`is_teacher = has_role(...)` / `is_admin = has_role(...)` 返回的是权限**类**（恒为真值），导致任何角色都按「管理员」放行；删除 `result["students"]` 中不存在的 `s.grade` 字段（`User` 无此字段，会抛 `AttributeError`）。

#### 新增代码记录

1. `apps/classroom/views.py`：
   - `ClassRoomViewSet.get_queryset` 学生角色收敛为「仅本校班级」。
   - `join` / `change` 增加「只能加入/转入本校班级」校验（`klass.school_id == request.user.school_id`）。
   - `import_students` 增加归属校验：教师仅能向自己所带班级（班主任或已通过科任）导入，学校仅能向本校班级导入。
   - `ClassStudentViewSet` / `ClassTeacherViewSet` 的 `get_queryset` 按角色收敛：学生仅本人、教师仅所带班级、学校仅本校。

2. `apps/exam/views.py`：
   - 新增 `_apply_paper_scope(user, qs)` 统一收敛试卷范围（教师→自建，学校/区县/市→创建人所属范围，省/超管→全部），`PaperViewSet.get_queryset` 与 `PaperPublishViewSet.create` 复用。
   - `PaperPublishViewSet.create` 增加发布越权校验；`PaperPublishViewSet.get_queryset` 按试卷归属收敛，防止越权撤回/重新发布他人试卷。
   - `PaperViewSet.draft` 增加「已发布试卷不可修改试题」保护。
   - `PaperQuestionViewSet` 补 `permission_classes`（原为空，默认放行）。
   - `AnswerViewSet` 补 `permission_classes` + `get_queryset` 数据范围收敛（原无权限，基础 CRUD 可被任意访问）。

3. `apps/exam/search_views.py`：`GlobalSearchView` 增加 `permission_classes`（教师/学校/区县/市/省/题库管理员），并按角色分别收敛班级、试卷、学生的搜索范围。

4. `apps/exam/stats_views.py`：`region_id` 查询参数增加越权校验——非省级账号只能按自己可见的行政区过滤，防止区县号跨区 / 跨市查询。

### 三、数据正确性修复

#### 删除代码记录

1. `apps/exam/backfill_views.py`：`_next_code` 由 `count() + 1` 改为「当日已有最大序号 + 1」，修复删除 / 软删记录导致编号撞唯一约束的问题。

#### 新增代码记录

1. `apps/common/middleware.py`：新增 `_resolve_user`——JWT 由 DRF 层校验，Django 中间件里 `request.user` 恒为 `AnonymousUser`，导致操作日志 `user` 恒为 null；现主动从 `Authorization` 头解出 `user_id` 落日志，session 认证兜底。

2. `apps/classroom/views.py`：新增 `_ensure_membership(klass, student)` 复活软删除的班级-学生关系，并在 `join` / `change` / `import_students` / `join_teacher` 中复用，避免退出后重新加入 / 换班时命中 `unique_together` 抛 `IntegrityError`。

3. `apps/exam/answer_views.py`：
   - `submit` 判通过条件改为 `total_full > 0 and my_score >= total_full * 0.6`，修复「满分为 0 时 0 分也判通过」。
   - `report` 班级平均分由「全库同卷答卷」收敛为「本人所在班级（已通过审核）的学生答卷」。
   - `list` 用 `Count("paper__paper_questions")` 注解 `_qcount`，`_item` 优先取注解值，消除逐条 `count()` 的 N+1。

4. `apps/exam/services.py`：`_tokens` 对纯字母连写 token（如多选答案 `"ABC"`）拆为单字母再比对，修复学生连写多选答案被误判为错。

5. `apps/exam/score_views.py`：
   - `ScoreImportView` 姓名兜底要求唯一匹配（`count() == 1` 才采用），避免重名误入他人名下。
   - `TeacherAnswerSheetScoreView` 增加「答卷尚未提交，无法评分」校验。

6. `apps/exam/backfill_views.py`：`BackfillDirectView` 增加去重校验（同一学生同一测评仅允许一条未驳回 / 未撤回的补录记录）。

7. `apps/exam/exports.py`：`build_workbook` 写入单元格前经 `_safe_cell_value` 清洗，以 `= + - @` 或制表符/回车开头的字符串前缀单引号转纯文本，防 Excel 公式注入。

8. `apps/exam/student_views.py`：`ExtracurricularViewSet.create` 增加图片类型（`image/*`）与大小（5MB）校验。

### 备注

- 生产库为阿里云 RDS（`DB_ENGINE=mysql`），本地 `.env` 默认连生产，本次全部验证强制 `DB_ENGINE=sqlite` 走本地库；**未对生产库执行 `migrate`**。部署时由人工在服务器 venv 中执行 `python manage.py migrate`，执行前请先确认 `exam_answer` / `exam_certificate` 无重复数据。
